# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是干净白底。
- 有小刘鸭。
- 小刘鸭承担核心动作，不只是装饰。
- 小刘鸭必须和 `assets/xiaoliuya-reference/contact-sheet.jpg` 里的参考形象一致。
- 小刘鸭保留白色圆角豆形身体、大圆眼、小号橙黄色扁嘴。
- 小刘鸭没有长脖子、羽毛、尾巴、真实翅膀、真实鸭掌。
- 使用小刘鸭 IP 的彩色表情配色，不是黑白线稿。
- 没有复刻旧案例构图或微信表情原图，而是为当前文章生成了新隐喻。
- 画面轻松、有表情感、有意思。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读。
- 灰黑色只用于轮廓、眼睛、少量文字和必要结构线。
- 橙黄色主要用于小刘鸭嘴部、脚和暖色重点。
- 低饱和黄/绿/蓝/粉/橙用于道具、地面块、桌椅、气泡和小面积情绪。
- 红色/粉色只用于重点、问题、提醒、结果或情绪强调。
- 蓝色只用于补充说明、反馈或系统状态。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有“常见坑 / Workflow / 系统架构图 / 路线图”等标题。
- 小刘鸭像真实鸭子、普通白鸭、鹅、企鹅、儿童绘本动物、3D 吉祥物或复杂商业插画。
- 小刘鸭缺少白色圆角豆形身体、大圆眼、小号橙黄色扁嘴。
- 小刘鸭出现长脖子、尖嘴、羽毛、尾巴、真实翅膀或真实鸭掌。
- 小刘鸭被重新设计成不属于参考图的新角色。
- 画面变成黑白线稿，缺少小刘鸭表情包配色。
- 小刘鸭只是表情贴纸，没有参与结构表达。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板，没有有趣的物理隐喻。
- 和 `assets/xiaoliuya-reference/` 或微信表情参考里的旧案例构图过于相似。

## 迭代方法

- 太普通：让小刘鸭成为动作主体，加入一个奇怪但成立的物理隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 角色不像：先查看 `assets/xiaoliuya-reference/contact-sheet.jpg`，重生成时强调 match the provided 小刘鸭 reference character exactly，并减少动作难度。
- 太黑白：强调 colorful Chinese sticker-style illustration、white duck body、orange-yellow beak、low-saturation yellow/green/blue/pink/orange props。
- 太幼稚：强调 clean sparse hand-drawn article illustration、not children's poster、not sticker sheet。
- 太商业：去掉精致阴影、渐变、复杂服装和厚重装饰。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成手绘场景。
- 太像旧表情：保留核心意思，换掉主物件、小刘鸭动作和中文标注。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。

## 交付判断

高质量图应该让读者先觉得“这个鸭子有点好笑”，然后 1 秒内看懂结构。

如果第一眼像表情包合集或教程页，而不是白纸上的轻松正文解释草图，就不合格。
