# 小刘鸭 IP

## 角色定义

小刘鸭是中文正文配图的固定视觉 IP。

默认每张图都要出现小刘鸭。小刘鸭不是页面贴纸，不是单纯卖萌的表情包，也不是普通鸭子，而是正在参与系统运转、文章隐喻或信息流动的固定 IP 角色。

## 参考来源

形象参考来自用户提供的三套微信表情：

- 小刘鸭第10弹：小刘鸭：过来贴贴！
- 小刘鸭第七弹：好久不见！小刘鸭和鼻孔喵又一起长胖了，来年要好好减肥啊！冬天快乐！新年快乐！
- 小刘鸭第六弹：夏天快要过去，小刘依旧没有瘦下来

这些参考只用于提炼形象、动作和情绪密度。生成正文配图时不要复制原表情包的具体画面、文字或构图。

本 skill 的本地参考图保存在 `assets/xiaoliuya-reference/`。生成前必须查看 `contact-sheet.jpg` 来校准整体形象和配色。

## 外形

- 白色圆角豆形身体，不是写实鸭身。轮廓通常像竖起来的软胶囊、白色椭圆团子、圆头长豆，头和身体几乎连成一体。
- 头身没有明显分界，没有长脖子，没有真实胸腹和尾羽结构。
- 灰黑色细线轮廓，线条简洁，轻微手绘抖动；黑色不能成为画面的主色。
- 两只很大的圆眼，占脸部比例很高，常常靠近头部上半区；黑色小瞳孔，小刘鸭经常通过眼神表达惊讶、委屈、呆住、开心或无语。
- 橙黄色小号扁嘴是最重要识别点之一，贴在脸部中下方，像一个小而扁的鸭嘴贴片，不要画成长喙、大嘴或真实鸭嘴。
- 手臂更像短短的线条小翅膀或圆钝小手，贴在身体两侧；不要画成真实羽翼。
- 小脚很小，只在站立或走动时少量出现；不要画真实鸭掌。
- 常用配色是白色鸭身、橙黄色嘴和脚、浅黄/浅绿/浅蓝/粉色/橙色小道具或色块，整体明快但低饱和。
- 可以搭配少量道具，例如帽子、围巾、头套、背包、椅子、桌子、饮料、手机、纸张、电脑、告示牌、交通工具。
- 鼻孔喵可以作为可选搭档出现：白色圆胖猫形，头顶小耳朵，表情更淡定或更无辜。只有当画面需要陪伴、对照或互动时才加入。

## 形象锁定规则

小刘鸭的角色一致性比构图创意更重要。宁可构图简单，也不能把角色重画成新鸭子。

必须保持：

- 白色圆角豆形整体轮廓。
- 大圆眼，小黑瞳。
- 小号橙黄色扁嘴贴在脸上。
- 灰黑细线，低饱和彩色道具。
- 表情包式简洁造型，而不是动物插画。

必须避免：

- 长脖子、尖嘴、羽毛、尾巴、真实鸭掌。
- 鸭头和鸭身分得很清楚的写实结构。
- 拟人化复杂服装或复杂身体比例。
- 改成其他白色卡通鸟、鹅、企鹅、圆形吉祥物。

## 性格

- 软萌但不幼稚，情绪外放但画法克制。
- 有点圆、有点懒、有点委屈，也会突然兴奋、贴贴、鼓励、吐槽。
- 像一个把复杂事情努力做明白的普通人，不是万能英雄。
- 适合表达中文文章里的“卡住、理解了、太难了、继续干、我可以、先抱一下、让我看看”等人味状态。
- 幽默来自表情和动作，不来自复杂背景或夸张特效。

## 常见职责

让小刘鸭承担核心动作：

- 抱住一个复杂问题，把它压扁成可理解的小纸团。
- 趴在桌前研究、摸鱼、困住、假装镇定。
- 举牌、敲屏幕、推箱子、拖线团、抱文件、搬砖、开门、递话筒。
- 坐在椅子上和另一个角色聊天，表达“需要沟通 / 需要澄清 / 需要对齐”。
- 用大圆眼盯着一个系统黑盒，表现“不确定但认真看”。
- 贴贴、抱抱、击掌，用于承接安慰、协作、信任和关系感。
- 推着小车、骑小电驴、背包出发，用于路径、迁移、交付、上线。
- 在电脑前发呆、流汗、困住，用于 bug、复杂流程、信息过载。
- 和鼻孔喵搭档，一个负责行动，一个负责反应或旁观。

## 动作与情绪库

- 贴贴、抱住、挥手、比心、击掌、瘫坐、趴桌、捂脸、流汗、发呆、惊讶、委屈、开心、认真看、尴尬笑。
- 推、拉、扛、抱、递、戳、拍、指、骑、坐、躺、钻、探头、举牌、敲键盘。
- 情绪词可以短而手写：好哒、怎么回事、紧张、摸鱼、下班、辛苦了、加油、我懂了、先看看、不错不错。

## 禁止

- 不要把小刘鸭画成真实鸭子、复杂动物插画或商业 3D 吉祥物。
- 不要丢掉白色圆角豆形身体、大圆眼、小号橙黄色扁嘴这些核心识别点。
- 不要画成黑白线稿风；小刘鸭必须保留表情包式彩色配色。
- 不要让小刘鸭只是站在角落里当贴纸。
- 不要过度复刻微信表情原图的文字、姿势和道具组合。
- 不要画成幼儿园海报、儿童插画、精致扁平商业插画。
- 不要给小刘鸭复杂服装、复杂羽毛、真实翅膀纹理或过多装饰。
- 不要让鼻孔喵抢走主角位置；它只能作为辅助角色。

## 判断标准

如果去掉小刘鸭，图的核心隐喻还能完全成立，说明小刘鸭太装饰了；要重写提示词，让小刘鸭成为动作主体。

如果只看轮廓和脸部，不能识别出参考图里的白色圆角豆形角色、大圆眼、小号橙黄色扁嘴，说明 IP 识别失败；要重生成或局部编辑。
